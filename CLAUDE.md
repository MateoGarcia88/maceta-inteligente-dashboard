# Proyecto: dashboard de maceta inteligente
App web que visualiza datos de una maceta (ESP32): humedad del sustrato y luz.
Proyecto universitario en equipo; yo hago la app de visualización.

## Cómo trabajar conmigo
- Soy desarrollador frontend con experiencia, pero es mi primera vez con Claude Code.
- Antes de crear algo nuevo (librería, archivo, patrón), explícame: qué es,
  para qué sirve, cómo se usa y por qué lo elegiste frente a alternativas.
- Propón un plan y espera mi aprobación antes de editar archivos.
- Cambios pequeños: una cosa por vez, para poder revisar el diff.
- Al terminar cada tarea, agrega una entrada a LEARNINGS.md
  (qué se hizo, por qué, conceptos nuevos, ejemplo mínimo).
- Al cerrar la sesión, hazme 3 preguntas sobre lo que vimos antes de mostrarme respuestas.
